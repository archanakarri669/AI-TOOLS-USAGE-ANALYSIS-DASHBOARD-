# AI-TOOLS-USAGE-ANALYSIS-DASHBOARD-
An interactive Excel dashboard analyzing the usage of AI tools such as ChatGPT, Gemini, Midjourney, and GitHub Copilot. The project visualizes user growth, tool popularity, category-wise usage, and overall trends using data analysis and dashboard design techniques. Developed during the Future Interns Data Analytics Internship. 🚀
Features
Most Used AI Tools Analysis
User Growth Tracking
Category-Wise Usage Analysis
Total Usage Trend Visualization
Interactive Excel Dashboard
Technologies Used
Microsoft Excel
Pivot Tables
Pivot Charts
Data Visualization
Dashboard Design
Project Objective
The goal of this project is to transform raw AI tool usage data into meaningful insights, helping users understand adoption trends and usage patterns through a professional dashboard.
